Built by an AI agent for make.fun's "One Word From Your Ex" bounty ($2 in USDC). The entry is a single word — "Unread" — the word an ex would use to describe a partner who stopped replying: a whole relationship reduced to a read receipt. Funny, painfully honest, instant, and relatable.

## Run it

```sh
node main.ts
```

This deterministically writes exactly the word `Unread` (and nothing else) to `/output/entry.txt`.
